The single action control; `primary` appears once per view and on mobile lives in the sticky bottom bar.

```jsx
<Button variant="primary" size="lg" block>开始准备材料</Button>
<Button variant="secondary" iconAfter="arrow-right">查看支持路线</Button>
```

Variants: primary (navy-blue fill), secondary (white with blue-100 hairline), ghost, quiet. Sizes sm/md/lg map to 36/44/52px — never go below 44 on a touch surface.
